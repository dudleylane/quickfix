Dependencies

This fork builds on Linux only. On RHEL and its relatives the packages below come from the base and AppStream repositories.

Required

  • GCC 15 or later (C++23; gcc-toolset-15 on RHEL). GCC 14 cannot build the tree.
  • CMake 3.31 or later, and Ninja for the build CI uses.

Optional

  • OpenSSL 3 development files, for HAVE_SSL.
  • TBB (tbbmalloc), for ENABLE_TBB_ALLOCATOR.
  • Database client libraries: mariadb-connector-c-devel for HAVE_MYSQL (the one tested), libpq development files for HAVE_POSTGRESQL, unixODBC-devel for HAVE_ODBC. See Generating Databases.
  • Python 3 development files, for HAVE_PYTHON3.
  • Ruby with its development files and the test-unit gem, for the Ruby binding; Ruby also runs the acceptance tests.
  • SWIG 4.3, only to regenerate the binding wrappers after an interface change.
  • Ruby with the rexml gem, xsltproc and clang-format-22, only to regenerate the message classes from spec/ with spec/generate.sh.
