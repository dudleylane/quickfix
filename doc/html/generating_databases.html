Generating QuickFIX Databases

The scripts are in src/sql/, one directory per database; run them from their own directory. The library must be built with the matching option (HAVE_MYSQL, HAVE_POSTGRESQL or HAVE_ODBC).

MySQL

With a MySQL or MariaDB server running, from src/sql/mysql, pass a user that may create a database, and its password:

./create.sh root password

create_user.sh then creates the quickfix user from user.sql. The client library CI builds against is mariadb-connector-c.


PostgreSQL

With a PostgreSQL server running, from src/sql/postgresql, pass a user that may create a database:

./create.sh postgres
./create_user.sh postgres

The first drops and creates the quickfix database and its tables; the second creates the quickfix role. The unit tests' configuration (test/cfg/ut.cfg) connects as that role with no password on localhost; CONTRIBUTING.md has the full setup CI's runner uses.


ODBC

OdbcStore and OdbcLog reach any database through an ODBC driver. CI runs them through psqlODBC against the PostgreSQL database above. src/sql/mssql/mssql.sql is a schema for Microsoft SQL Server, to load with that server's own tools; there is no separate MSSQL store.
