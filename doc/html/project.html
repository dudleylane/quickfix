Setting Up Your Project

An install provides a CMake package and a pkg-config file. Code using the headers must be compiled as C++23. Include headers as <quickfix/...>.

CMake

cmake_minimum_required(VERSION 3.31)
project(myapp CXX)
set(CMAKE_CXX_STANDARD 23)
find_package(quickfix 22 CONFIG REQUIRED)   # any 22.x: the major version is the soname
add_executable(myapp main.cpp)
target_link_libraries(myapp PRIVATE quickfix::quickfix)

Point CMake at a non-standard prefix with -DCMAKE_PREFIX_PATH=/that/prefix. A project that adds this source tree with add_subdirectory or FetchContent links the same quickfix::quickfix target.

pkg-config

g++ -std=c++23 main.cpp $(pkg-config --cflags --libs quickfix)

An install under /usr/local puts quickfix.pc in /usr/local/lib/pkgconfig, which not every distribution searches: set PKG_CONFIG_PATH, and make sure the dynamic linker finds /usr/local/lib (ldconfig or LD_LIBRARY_PATH).

What the install records for you

QuickFIXBuildConfig.h, installed with the headers, records how the library was built: SSL, the database backends and the TBB allocator. A program can include the SSL or database headers of an install built with them without defining HAVE_SSL, HAVE_MYSQL and the rest itself, and defining one the library was built without is an error at compile time rather than at link time.
