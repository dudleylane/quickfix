Building QuickFIX

This fork builds on Linux only, with CMake. README.md in the source tree is the full reference; this page is the short version. See Dependencies for what to install first.

Compiler

The tree needs C++23 and GCC 15 or later: FieldMap.h uses std::flat_map, which GCC 14's standard library does not have. On RHEL and its relatives, GCC 15 comes from gcc-toolset-15:

export CC=/opt/rh/gcc-toolset-15/root/usr/bin/gcc
export CXX=/opt/rh/gcc-toolset-15/root/usr/bin/g++
export PATH=/opt/rh/gcc-toolset-15/root/usr/bin:$PATH
export LD_LIBRARY_PATH=/opt/rh/gcc-toolset-15/root/usr/lib64

Configure, build, install

cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release -DHAVE_SSL=ON
cmake --build build -j"$(nproc)"
sudo cmake --install build

Always pass -DHAVE_SSL=ON or -DHAVE_SSL=OFF as you intend: configure rewrites the tracked src/C++/config.h from it. Libraries and programs are written to lib/ in the source tree, whichever build directory you use; give a second build tree its own -DQUICKFIX_LIB_OUTPUT_DIR.

Options

OptionDefaultMeaning

QUICKFIX_EXAMPLESONThe examples, and the at and pt test drivers
QUICKFIX_TESTSONThe unit tests, ut

Testing your build

There is no ctest target. From test/:

./ut --quickfix-config-file cfg/ut.cfg --quickfix-spec-path ../spec   # unit tests
./runat.sh 54321                                                       # acceptance tests (needs Ruby)

See Testing.

The Python and Ruby bindings

Python: configure with -DHAVE_PYTHON3=ON; cmake --install puts the module in the interpreter's site-packages for the prefix. Ruby: build with src/ruby/make_ruby.sh, then install with src/ruby/install.sh. Rebuild the Ruby module after every library upgrade that changes the major version.

Packages that install upstream QuickFIX, such as vcpkg install quickfix, do not install this fork.
